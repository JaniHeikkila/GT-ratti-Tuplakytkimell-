# GT-ratti-Tuplakytkimell-
USB-ratti simulaattorikäyttöön. Ratin ohjauksesta vastaa Raspberry Pi Pico (RP2040) -mikrokontrolleri, joka välittää painikkeiden, kiertokytkimien, vaihdeläpysköjen ja tuplakytkimen syötteet tietokoneelle USB HID -peliohjaimena.
